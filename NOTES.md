# Notes по тестовому заданию

## Что сделано

### Задача 1: Распределение заказов (Dispatch)

- Исправлена ошибка в функции `findNearest` (файл `task-1-dispatch/src/router.ts`).
- **Проблема:** При вызове функции `distanceKm` аргументы координат второго филиала передавались в неправильном порядке (сначала долгота `b.lon`, потом широта `b.lat`). Из-за этого формула расчета расстояния выдавала некорректные результаты, и алгоритм выбирал неверный филиал (например, Астану вместо Алматы).
- **Решение:** Порядок аргументов изменен на правильный `(order.lat, order.lon, b.lat, b.lon)`. Теперь алгоритм корректно выбирает ближайший филиал.

### Задача 2: Онлайн-запись (Booking)

- Исправлена ошибка в функции `overlaps` (файл `task-2-booking/src/time.ts`).
- **Проблема:** Использовался нестрогий оператор `<=` для сравнения временных интервалов. Из-за этого записи, которые просто стыкуются границами (например, с 10:00 до 11:00 и с 11:00 до 12:00), считались пересекающимися, и система запрещала записывать клиента сразу после предыдущего.
- **Решение:** Оператор заменен на строгий `<`. Теперь записи, идущие друг за другом, не конфликтуют.
